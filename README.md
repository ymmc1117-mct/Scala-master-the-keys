# 🎹 Scala — 音階マスター

ピアノの音階（長調・短調 各12種、計24音階）を効率的に暗記するためのPWAアプリです。

## 機能

- **3アカウント対応** — 家族・友人間でアカウントを分けて使用可能
- **学習モード** — 全24音階を一覧表示。タップで音列・調号の詳細を確認
- **テストモード** — 2種類の問題形式（調号を答える / 音階名を答える）
- **進捗確認** — アカウントごとに習得状況をビジュアルで確認
- **お祝い演出** — 全問正解時にコンフェッティアニメーション
- **PWA対応** — ホーム画面に追加してオフラインでも使用可能

## GitHub Pages でのデプロイ手順

1. このリポジトリを GitHub にプッシュ
2. Settings → Pages → Branch: `main` / `/ (root)` を選択して Save
3. `https://<username>.github.io/<repo-name>/` でアクセス可能

## PWA としてホーム画面に追加（iPad）

1. Safari でアプリのURLを開く
2. 共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」を選択

## ファイル構成

```
├── index.html      # メインアプリ（単一ファイル）
├── manifest.json   # PWAマニフェスト
├── sw.js           # Service Worker（オフライン対応）
├── icon-192.png    # アイコン 192×192（別途用意）
├── icon-512.png    # アイコン 512×512（別途用意）
└── README.md
```

> **アイコンについて**: `icon-192.png` と `icon-512.png` は別途作成してください。
> Canva や Figma などで 🎹 をモチーフに作成することをおすすめします。

## データ保存

データはブラウザの `localStorage` に保存されます。
同じデバイス・同じブラウザで継続使用できます。
